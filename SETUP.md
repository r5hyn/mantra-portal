# Mantra Homes — Booking App Setup Guide

This guide takes you from zero to a live booking system in about 20 minutes.

---

## What you'll need

- A computer with internet access
- Your ServiceM8 API key (see Step 2)
- A free Vercel account (see Step 4)

---

## Step 1 — Install Node.js

If you don't already have Node.js installed:

1. Go to **https://nodejs.org**
2. Download the **LTS** version and install it
3. To check it worked, open Terminal (Mac) or Command Prompt (Windows) and type:
   ```
   node --version
   ```
   You should see something like `v20.11.0`

---

## Step 2 — Get your ServiceM8 API Key

1. Log in to ServiceM8 on your computer
2. Go to **Settings → Integrations → API**
3. Click **Create API Key**
4. Give it a name like "Booking App"
5. Copy the key — you'll need it in Step 3

---

## Step 3 — Configure your environment

In the `mantra-booking` folder, create a file called `.env.local` (copy from `.env.example`):

```
SERVICEM8_API_KEY=paste-your-key-here
BOOKING_SECRET=any-long-random-string-here
APP_URL=http://localhost:3000
```

For `BOOKING_SECRET`, just type any long random string — e.g. `mantra-homes-booking-2024-xk9q2p`.
This is used to secure the booking links so they can't be tampered with.

---

## Step 4 — Test it locally first

Open Terminal / Command Prompt, navigate to the `mantra-booking` folder and run:

```bash
npm install
npm run dev
```

Then open **http://localhost:3000** in your browser.

- The scheduler page should load and show the job search
- To test the booking page, you'd need valid URL params (generated by the scheduler page)

---

## Step 5 — Deploy to Vercel (free hosting)

### 5a. Create a Vercel account
Go to **https://vercel.com** and sign up for free (you can use your Google account).

### 5b. Install the Vercel CLI
```bash
npm install -g vercel
```

### 5c. Deploy
In Terminal, from the `mantra-booking` folder:
```bash
vercel
```

Follow the prompts:
- Link to your Vercel account
- Set project name: `mantra-booking` (or whatever you like)
- Accept the default settings

At the end, Vercel will give you a URL like `https://mantra-booking-abc123.vercel.app`

### 5d. Set your environment variables in Vercel
1. Go to **https://vercel.com/dashboard**
2. Click your project → **Settings** → **Environment Variables**
3. Add each variable from your `.env.local`:
   - `SERVICEM8_API_KEY`
   - `BOOKING_SECRET`
   - `APP_URL` → set this to your Vercel URL, e.g. `https://mantra-booking-abc123.vercel.app`

4. Go back to **Deployments** and click **Redeploy** so the variables take effect

---

## Step 6 — Bookmark the scheduler page

The scheduler (booking link generator) lives at:
```
https://your-app.vercel.app/
```

Bookmark this in your browser, or add it to the home screen on your phone.
The team uses this page to send booking links — it never needs to be shared with customers.

The customer-facing booking page is automatically linked from the SMS. Customers never
need to know the scheduler URL exists.

## Troubleshooting

### "ServiceM8 API error 401"
Your API key is wrong or in the wrong format. Check it was copied correctly in `.env.local`.
Some ServiceM8 accounts may need the key formatted differently — try changing the auth line in
`lib/servicem8.js` from `${apiKey}:` to `:${apiKey}` if 401 errors persist.

### SMS sends but engineer shows no availability
Check that the engineer has their working hours/schedule set up in ServiceM8.
The availability checker looks at existing job activities — if the engineer has no jobs
scheduled at all, every slot will show as available.

### "No mobile number" error
The job contact needs a mobile number entered in ServiceM8 (on the job or the client record).

### Saturday availability
By default, Saturdays are included and Sundays are excluded.
To exclude Saturdays too, open `pages/api/availability.js` and change:
```js
const SKIP_DAYS = new Set([0]);       // Sunday only
```
to:
```js
const SKIP_DAYS = new Set([0, 6]);    // Sunday + Saturday
```
Then redeploy with `vercel --prod`.

## How it works (quick summary)

1. Scheduler opens the app, searches for a job, picks engineer + duration, clicks **Send**
2. App sends an SMS via ServiceM8 (appears in the job's activity feed, from your number)
3. Customer taps the link, sees Morning / Afternoon buttons for the next 3 weeks
4. Customer picks a slot → the job activity is created in ServiceM8 and job status set to **Work Order**
5. The booking link expires after 3 weeks and can only be used once
